# Hierarchy Inspector

A Unity Editor extension that turns the Hierarchy window into a workspace: row visuals, per-object styling, virtualization folders, bookmarks, and a style clipboard.

## Documentation

Full user documentation lives on GitBook. The source is in [`docs/`](docs/).

## Repo layout

- `Assets/Plugins/HierarchyInspector/` houses the runtime data component, the editor overlay, the theme assets, and the demo scene builder.
- `docs/` is the GitBook source (markdown + assets).
- `.gitbook.yaml` configures the GitBook GitHub Sync.
