# Hierarchy Decorator

Welcome to the **Hierarchy Decorator** documentation.

Hierarchy Decorator enhances Unity's default Hierarchy window with:

- Native-style toggles (active state, static flags, layer, tag, and more) drawn inline per row
- A themeable visual layer — colors, icons, and row styling
- A style clipboard for copy/pasting visual configuration between objects
- Per-object overrides driven by configurable rules

This documentation is the user-facing reference. For source and contribution details, see the [GitHub repository](https://github.com/OverGast/Hierarchy-Decorator).
