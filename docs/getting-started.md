# Getting Started

_This page is a stub — fill in once the asset is extracted._

## Installation

1. Download the latest `HierarchyInspector.unitypackage` from the releases page.
2. In Unity, go to **Assets → Import Package → Custom Package…** and select the file.
3. Import all assets when prompted.

## First Run

After import, open **Tools → Hierarchy Inspector → Settings** to configure the extension.
